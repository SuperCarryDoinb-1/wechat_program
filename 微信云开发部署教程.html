微信云开发部署教程

按照“点哪里、填什么、看到什么算成功”的顺序，完成数据库创建、云函数部署与真实答题验证。

AppID 和云环境 ID 已在项目代码中填好。现在主要是在微信开发者工具中完成部署。界面按钮可能因版本略有不同，下面同时列出了常见名称。

第一步：打开项目，分清两个操作窗口

  1. 打开微信开发者工具，用有这个小程序开发权限的微信扫码登录。
  2. 打开现有项目 wechat_program。如果项目列表里没有，点击导入，选择目录 。
  3. 确认导入时的 AppID 是 YOUR_WECHAT_APPID。
  4. 进入项目后，点击顶部的云开发。

接下来会用到两个界面：

界面用途
开发者工具主窗口：有代码文件列表、手机模拟器上传本地云函数、编译小程序
云开发控制台：有数据库、云函数、环境设置创建集合、设置权限、查看云端数据
每次进入云开发控制台，先确认当前环境 ID 是 YOUR_CLOUD_ENV_ID。数据库和三个云函数都要放在同一个环境。

第二步：创建 results 集合

“集合”可以理解成保存测评结果的一张表。

  1. 在云开发控制台中点击数据库。有的界面叫文档型数据库。
  2. 找到集合或集合管理。
  3. 点击添加集合、新建集合或旁边的 ＋。
  4. 在集合名称里输入 results。
  5. 点击确定或创建。

名称全部小写，末尾有一个 s，前后不要有空格。如果列表里已经有 results，直接使用，不用重复创建。

成功标志：集合列表中出现 results，点击后显示空数据列表。里面没有记录是正常的，不需要手动添加数据或字段。

第三步：设置 results 的安全规则

  1. 选中刚创建的 results。
  2. 找到权限设置、权限管理或数据权限。
  3. 选择自定义安全规则。有的界面需要点击切换到安全规则。
  4. 如果出现代码编辑框，选中这个编辑框中的全部内容，替换为下面的代码。
{
  "read": false,
  "write": false
}
  1. 点击保存、确定或应用。
  2. 再次打开权限设置，确认内容已经保存。

官方的新界面入口是：文档型数据库 → 集合管理 → 权限管理 → 切换到安全规则。参见 官方安全规则说明。

这里的意思是：小程序客户端不能直接读写这个集合，数据统一由项目里的云函数处理。设置为 false 不会阻止本项目的云函数保存结果。

cloudfunctions/database.rules.json 是项目中保存规则的文件。仅有这个文件不会自动设置云端权限，所以需要完成上面的粘贴与保存。

第四步：给本地 cloudfunctions 选择云环境

切回开发者工具主窗口，就是能看到代码文件的窗口。

  1. 在左侧文件列表中找到 cloudfunctions。
  2. 点击文件夹左边的小箭头，展开它。应该能看到下面的结构。
cloudfunctions
├─ genContent
├─ getResult
├─ ping
└─ database.rules.json
  1. 用鼠标右键点击最外层的 cloudfunctions 文件夹。
  2. 找到类似当前环境、选择云环境或切换环境的菜单。
  3. 选择环境 ID 为 YOUR_CLOUD_ENV_ID 的环境。列表有时先显示你创建环境时填写的名称，请对照环境详情确认。
  4. 等待文件列表或云函数信息刷新。
成功标志：再次右键查看时，这个环境已经被选中。

如果这里没有环境可选：

  • 确认你在同一个项目中已经打开过云开发控制台。
  • 确认控制台能看到这个环境。
  • 关闭并重新打开项目后，再试一次。
  • 如果控制台有环境，但右键菜单始终没有，截图求助，不用重新创建项目或环境。

第五步：依次上传三个云函数

“上传并部署”就是把电脑上的后端代码放到微信云端，让小程序可以调用。

先部署 ping：

  1. 在左侧展开 cloudfunctions。
  2. 右键点击 ping 文件夹。
  3. 选择上传并部署：云端安装依赖。有的版本叫“上传并部署：云端安装依赖（不上传 node_modules）”；首次部署也可能显示“创建并部署：云端安装依赖”。
  4. 如果弹出目标环境确认，核对是 YOUR_CLOUD_ENV_ID。
  5. 等待上传和安装结束，看到成功提示。

然后用同样的方法，依次部署 genContent 和 getResult。

要右键文件夹，不是文件夹中的 index.js 文件。每个云函数需要完整上传，里面的 package.json 和 shared 等文件也要一起带上。选择“云端安装依赖”后，不需要先在电脑上手动安装这些依赖。参见 官方部署说明。
云函数作用
ping检查小程序能否调用云端
genContent保存测评结果并返回解读
getResult查询分享链接对应的公开结果

上传完后，打开云开发控制台 → 云函数，刷新列表。

成功标志：云端列表里能看到 ping、genContent、getResult 三个函数，并且部署已完成。

如果某个函数显示部署失败，展开它的错误详情，保留错误文字或截图。不要仅凭文件夹已经出现在列表里就判断成功。

第六步：把 genContent 执行超时改为 15 秒

  1. 在云开发控制台进入云函数或函数列表。
  2. 点击 genContent，进入函数详情。
  3. 找到配置、函数配置或配置管理。
  4. 找到执行超时时间或超时时间。
  5. 如果有编辑按钮，先点击编辑。
  6. 将数值改为 15。
  7. 确认旁边单位是秒，然后点击保存。

如果界面明确以毫秒为单位，则填 15000；以页面标注为准。

成功标志：保存后，配置页面显示执行超时时间为 15 秒。官方说明中，函数详情页可查看运行内存、超时时间和调用日志。参见 官方函数入口说明。

这里改的是云函数的执行超时，不用改项目 config/env.js 中的 timeoutMs: 8000，它是前端等待时间。

第七步：先检查小程序能不能连接云函数

这一步只检查连接，不会创建测评结果。

  1. 回到开发者工具主窗口。
  2. 点击顶部编译，等手机模拟器显示小程序首页。
  3. 打开调试器。通常在窗口下方，如果没显示，可以点击工具栏中的调试器。
  4. 找到 Console / 控制台 标签。
  5. 在最下面可以输入代码的位置，粘贴以下完整代码。
wx.cloud.callFunction({
  name: 'ping',
  data: {}
}).then(res => {
  console.log('云端连接结果：', res.result)
}).catch(err => {
  console.error('云端连接失败：', err)
})
  1. 按回车执行。
这段代码粘贴到开发者工具的 Console，不是 Windows 的 PowerShell，也不是某个代码文件。

正常情况下，会输出类似：

{
  ok: true,
  message: "ok",
  database: "unchecked"
}
看到 ok: true，说明小程序已经成功调用 ping。

database: "unchecked" 是正常的，意思是这次只检查云函数连接，还没有检查数据库。下一步通过真实答题验证保存。

如果先看到 Promise {<pending>}，继续等后续输出，它本身不是报错。

第八步：完成一次新测评，检查数据库

  1. 在手机模拟器的小程序首页，点击开始测试。
  2. 完整回答 12 道题。
  3. 进入结果页后，等待解读内容出现。
  4. 如果你之前已经做过测试，请点击重新测试，完成一轮新的答题。仅打开旧结果页可能使用本地缓存，不一定新增云端记录。
  5. 打开云开发控制台。
  6. 确认环境是 YOUR_CLOUD_ENV_ID。
  7. 进入数据库 → results。
  8. 点击刷新按钮。
成功标志：results 里出现一条新记录。展开后，你应该能看到以下字段。
字段含义
_id这条结果的唯一编号
_openid调用者的微信身份标识
code测评类型，例如 TEM
scores测评分数
answers12 道题的答案
roast结果文案
tips建议
source文案来源
createdAt创建时间

暂时没有配置 AI 模型时，source 是 mock 属于正常现象。项目会使用示例文案，但这条记录确实保存在云数据库中。可以先把云端保存和分享功能跑通，再接入 AI 模型。

如果界面显示的是离线结果，而 results 里没有记录，说明答题功能可用，但云端保存还没有成功。

第九步：遇到问题时，按现象检查

看到的情况先检查哪里
找不到云函数、FUNCTION_NOT_FOUND三个函数是否部署成功，部署环境是否正确
非法的 env、环境访问失败环境是否属于或已关联当前 AppID，环境 ID 是否一致
DATABASE_WRITE_FAILED当前环境是否创建了小写 results 集合
Cannot find module、依赖安装失败是否选择了“云端安装依赖”；打开部署日志查看具体错误
执行超时genContent 的 15 秒配置是否保存成功，再查看函数日志
结果页正常，但数据库为空是否重新完成了答题；是否查看了正确环境并刷新集合
在云端测试 genContent 提示 UNAUTHENTICATED请从小程序中答题调用，云端测试面板可能没有真实用户身份

查看后端错误日志

进入：云开发控制台 → 云函数 → genContent → 日志。

选择最近的时间段，找到刚才答题对应的调用记录，展开详情。截图求助时带上错误文字即可。

可以先做到第三步：创建 results 并保存安全规则。如果中途找不到按钮，发送当前页面截图，即可根据你实际看到的界面继续操作。
