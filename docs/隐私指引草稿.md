# 隐私保护指引配置草稿

**仅用于填写后台前核对；不是已生效的最终政策。** 运营者、联系方式、保留期限、删除处理与模型接收方尚未确定，不能直接带着待填项发布。首页和保存海报流程已提供打开微信官方隐私指引的入口，后台配置后仍需真机验证能打开正确文本。

| 数据/能力 | 现有实现与用途 | 公开范围 |
| --- | --- | --- |
| 12 个固定选项、三轴分数、类型 | 本地计算；云模式写 results，用于结果与配对 | 分享查询只返回类型、分数 |
| 微信 OPENID | 云函数从可信上下文取得，随结果存储；没有自建账号登录页 | 不向朋友查询接口返回 |
| rid、fromRid、创建时间 | 关联本次结果与邀请；支持读取朋友类型和配对 | rid 随原生分享链接公开 |
| 点评、3 条建议及来源 | 模型生成或预设回退，存云端结果；缓存本机当前结果 | getResult 不返回这些内容 |
| 本机当前结果缓存 | 含本轮答案和内容，下一轮完成后覆盖；无历史列表 | 本机展示 |
| 相册写入 | 用户主动保存个人/双人海报后调用相册写入 | 用户自行决定图片后续分享 |
| 提交给模型的输入 | 固定题目与选项文本、类型及人设 | 仅发给实际配置的模型服务；不主动发送 OPENID、rid |

实际提供商可能记录调用日志与基础网络信息，其范围、区域和保留期需按所选服务核对，不能声称完全不留存。公开结果通过 rid 查询，不按收件人限制访问；用户分享后，持有链接者可能继续转发。

用户可拒绝相册授权，个人测试仍可使用。代码不读取相册照片、通讯录、定位、电话、头像昵称，不提供自由输入聊天或文件上传。题目里描述的“聊天记录”等情境不表示本程序实际读取这些信息。

必须补齐的后台信息：

- 运营主体全称、联系邮箱或受理渠道。
- results、云函数日志及提供商日志的实际保存期限与依据。
- 查询、更正和删除请求的受理方式、身份核验方式、响应时限。
- 实际模型及云服务的主体名称、数据接收范围和相应协议。
- 小程序后台隐私接口及用途声明，与实际代码一致。

当前云端每次完成会创建新记录，**尚无自动过期删除任务，也没有应用内清空云数据入口**。不能写“退出即删除”或“只保存最近一次云结果”。如采用人工删除，应先确定受理渠道和操作流程，验收实际处理后才能对外承诺。

AITI.md 中写的 `requiredPrivacyInfos` 不应原样加入 app.json。微信官方示例使用的是 `requiredPrivateInfos`，该字段不是所有隐私能力的通用清单；项目没有相应定位调用，本轮没有为保存相册猜填无依据的字段。相册仍需后台隐私声明、用户隐私同意和相册授权。参考 [微信官方 app.json 示例](https://github.com/wechat-miniprogram/miniprogram-demo/blob/master/miniprogram/app.json)、[微信官方隐私接口定义](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)。真实配置有效性以本账号平台校验为准。
