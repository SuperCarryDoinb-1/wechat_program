# 首次开通云开发

2026-09-10 用户确认：尚未开通。当前 `config/env.js` 保留 mock，测试不会写入真实数据库，也不会调用真实模型。

1. 用小程序管理员或有权限的开发者账号登录微信开发者工具，导入本项目，确认 AppID 属于你的账号。当前项目已保留用户填写的 AppID，不能以测试号或游客身份替代真实账号验收。
2. 在开发者工具的「云开发」入口创建环境；环境名称按自己习惯填写。套餐、免费额度及费用以账号实时显示为准，确认费用后由你开通，不在这里假定免费。
3. 取得环境 ID，例如控制台中的完整字符串；环境 ID 可填入项目，API key 和其他密钥不要发送到聊天或写进前端。环境与小程序关联方式以控制台为准。
4. 创建数据库集合 `results`，按 `cloudfunctions/database.rules.json` 设置客户端禁止直接读写。数据由云函数写入并按白名单查询。
5. 按 [M4 部署步骤](M4-deploy.md) 同步并上传 `ping`、`genContent`、`getResult`，选择云端安装依赖。先用无模型的云端示例内容验证真实落库与分享，再接入模型。
6. 把 `config/env.js` 中 `mode` 改为 `cloud`，`cloudEnvId` 填实际 ID，重新编译。若需诊断，临时开启 `showDiagnostics`，结束后关闭。
7. 重新答题，不沿用旧 mock 结果。确认生成真实 rid、getResult 能读取朋友的 code/scores，两个账号按 [M6 报告](M6-report.md) 完成配对。
8. 选择真实模型提供商，在云函数环境变量中配置凭据并完成至少 10 次调用验收。只有实际模型生成的内容才标注「AI 生成」。

开通环境不等于取得 AI 功能上线资格。请先确认小程序主体类型与账号允许的服务类目；使用 CloudBase AI 的相关发布材料参见 [官方 AI 发布说明](https://docs.cloudbase.net/ai/release/release-mp) 和 [云开发在用证明](https://docs.cloudbase.net/ai/release/algorithm-filing)。实际要求取决于主体、提供商和功能，需由账号后台核对，不能直接把本项目认定为已满足。

下一次联调需要：实际环境 ID、主体类型（个人或企业）、部署结果或错误文本。不需要提交 API key。
