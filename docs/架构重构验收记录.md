- `pages/` 全部入口、JSON、WXML、WXSS 内容一致。
- `components/`、`config/`、`assets/`、`cloudfunctions/` 全部文件内容一致。
- `app.js`、`app.json`、`app.wxss` 内容一致。
- 评分、配对、公开结果校验、海报平台适配 / 绘制、分享、宠物逻辑均未修改。
- 首页、答题、结果三个控制器的初始 `data` 深比较一致；原有方法 / 事件名全部保留。
- 原有业务测试文件 M0～M7、评分、宠物和流程测试未修改；仅扩展架构测试与测试入口，并新增流程内核测试。
