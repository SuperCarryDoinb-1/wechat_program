运行 `node tests/run.js`。M1 独立脚本输出 10 组通过；Node 测试运行器统计 M0、M2、M3 共 27 项通过、0 失败。单独运行 M3：`node tests/m3.test.js`。

测试使用真实页面与组件 JS，通过替身验证生命周期、属性观察器、计时和数据更新。没有实际执行微信渲染器，不能证明文字溢出、样式兼容、动效视觉或设备帧率；这些在本模块保留为待验收项。

坐标图绘图区四周预留标签与点半径空间，原始坐标 `(-1,+1)` 在左上，`(+1,+1)` 在右上，`(-1,-1)` 在左下，`(+1,-1)` 在右下。x=0、y=0 位于中心。主导徽章按最终类型第三个字母决定；原始坐标与类型在隐藏款转型边界可能不同，延续 M1 规则。

所有展示文案保存在 `config/`；人设关系按代码解析名字，更名不需要修改页面。动效时长配置为 1200ms，CSS 同步使用 1.2s；若调整配置，需同步修改结果页样式中的时长。减少动态效果偏好下禁用 CSS 动画，仍可跳过揭晓状态。

组件属性与数据观察器参考[微信官方 Component 类型定义](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.component.d.ts)。页面和组件仅使用已有原生能力，本轮未安装依赖或调用云端。
