# 进度条小人

## 当前使用素材

- 使用 `assets/quiz/human-runner-cutout.png`，由内置 image_gen 根据用户原图 `assets/quiz/human-runner.png` 抠图生成。
- 仅保留小人，移除矩形背景、地面阴影和身外速度线，背景使用真实透明通道；小人白色身体仍保持可见。
- 显示尺寸为 28 × 34 px，宽度从 36 px 收窄至 28 px，高度不变。
- 使用 `scaleToFill` 收窄显示比例，继续随进度移动，进度条经过小人中部。
- 通过 `config/quiz.js` 中的 `runnerFilters` 将白色身体映射为当前 `sceneColor`；题目框和小人共用该颜色，切题时同步变色。滤镜保持透明通道和黑色轮廓，尺寸不变。
