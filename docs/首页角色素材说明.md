# 首页 AI 字形角色

更新：2026-09-12。

## 设计与实现

- 根据项目根目录 AI.png 重绘 A 字形主体与右侧斜笔画，填实 A 的上部内孔用于放置表情，保留下部开口。
- 黄色主体、紫色斜笔画、黑色描边与硬阴影，融入 Fun Emoji 的 cute 眼睛与 cute 嘴巴，补充腮红与身体高光。
- 用户链接只指定 fun-emoji 风格，没有指定种子或某张表情；实现固定 seed=AITI、eyes=cute、mouth=cute，避免每次进入随机变化。
- 保留首页单行标题、自适应字号、蓝色展台和黄色开始按钮。
- 图形以内嵌 SVG 背景保存在 pages/index/index.wxss 中，无运行时网络依赖。可单独查看 [角色矢量校样](aiti-mascot.svg)。
- assets.hero 为空时显示该角色。此次未改动评分、答题与分享逻辑。

## 素材与许可

表情来自 [Fun Emoji Set / Davis Uche](https://www.figma.com/community/file/968125295144990435)，通过 [DiceBear Fun Emoji](https://www.dicebear.com/styles/fun-emoji/) 获取，采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。

[固定参数的表情源图](https://api.dicebear.com/9.x/fun-emoji/svg?seed=AITI&eyes=cute&mouth=cute)。保留眼睛与嘴巴路径，缩放、平移并将黑色调整为页面墨黑；移除原方形背景，替换为用户提供轮廓的矢量改绘。改编图亦采用 CC BY 4.0，许可与变更说明保存在 assets/fun-emoji-NOTICE.txt，SVG 内也保留作者和许可说明。此前 Tabler 表情已不再用于首页，旧许可文件作为历史记录保留。
