## 验证证据与边界

执行 `node tests/run.js`：M1 10 组通过；Node 测试运行器统计 M0 + M2 共 18 项通过、0 失败。其中 M2 单独运行方式为 `node tests/m2.test.js`。

M2 行为测试载入真实 `pages/quiz/quiz.js`，用可控计时器检验每一次切题，用内存替身检验存储及导航调用。因此能够验证应用逻辑和调用顺序，但不能验证微信 WXML/WXSS 解析、工具版本兼容性、实际设备字体及视觉尺寸。

小屏采用自然文档流，不固定操作栏，也不锁定页面高度。内容较长时允许滚动到第四选项和「上一题」，切题后滚动回顶部。图片缺失与加载失败均提供同尺寸占位。

## 存储约定

键：`aiti:current-result:v1`。只覆盖当前完整结果，不建立历史记录。

```js
{
  version: 1,
  answers: [0, 2, 3, 2, 1, 1, 2, 2, 0, 1, 1, 3],
  code: 'TEM',
  scores: { /* 原始分数 */ },
  coords: { x: 0, y: 0 }, // 以实际计算值为准
  rarity: 'hidden',
  createdAt: 0 // 实际保存时的毫秒时间戳
}
```

中途作答仅存在当前页面内存。退出答题页后丢弃草稿；后台切换仅暂停计时并保留当前页面状态。保存失败时不跳转；跳转失败时保留答案与已存结果并提供重试。后续 M3 从这一约定读取结果。
