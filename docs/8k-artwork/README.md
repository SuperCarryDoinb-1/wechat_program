# AITI · 8K 图稿

本目录包含 25 张由原始绘图指令重新渲染的 PNG，不是把原有小图拉伸放大。

| 内容 | 数量 | 像素尺寸 | 位置 |
| --- | --- | --- | --- |
| 个人海报 | 8 | 4318 × 7680 | `docs/poster-check/` |
| 双人关系示例海报 | 8 | 4318 × 7680 | `docs/pair-poster-check/` |
| 类型及邀请封面 | 9 | 7680 × 6144 | `assets/share/` |

这里的 8K 指图像长边 7680 像素；竖版按原海报比例保留，并非电视的横向 7680 × 4320 比例。双人图稿是四档关系及四种特配的示例，任意两类型组合可在小程序内选择「8K 超清」导出。

小程序页面使用原生文字和代码图形，显示细节受设备屏幕限制，不会因为标注 8K 而超过屏幕的实际分辨率。本目录仅用于原图查看、展示与打印，不放入小程序运行包。聊天分享缩略图的呈现仍由微信控制。

生成命令：先执行 `node tests/build-poster-previews.js`，再执行 `tests/render-poster-previews.ps1 -Ultra`。本地图稿使用 GDI 绘制，不是微信截图；实际字体与微信 Canvas 可能有差异。小程序码仍使用待上线占位，不能扫码跳转。

小程序内：结果页选择「8K 超清」，然后保存个人或双人海报。默认保留标准导出；8K 导出会验证实际尺寸，尺寸不符或设备失败时提示重试，不静默保存低清版本。导出完成或报错后释放画布缓冲。8K 设备兼容性、耗时与相册保存尚待真机验证。
